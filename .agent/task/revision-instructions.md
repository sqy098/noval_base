# 第1-3章修改指令

## 评审总结

**核心问题**：情绪释放不够充分。220年的冲击、父亲的死、爱夏的消失，这些核心痛点处理得过于克制。

**人物设定**：阿尔斯是"行动快于思考"的人，应该有更多冲动、失控、后悔的时刻。

## 第1章修改要点

### 致命伤：220年冲击的情绪释放不足

**具体修改**：
1. 阿尔斯看到"685年"计算出220年后的反应要更强烈：
   - 不只是"手抖"，要有生理反应：腿软、呕吐感、眼前发黑
   - 可以有失控的行动：直接冲向工人质问、抓住文件反复确认
   - 内心独白要更混乱："不可能不可能不可能"的重复

2. 对安妮丝和C.C.的质问要更激烈：
   - "你们是谁？为什么在这？"
   - 不要太快接受她们的存在
   - 可以有短暂的对抗（推开、拒绝回答）

3. 工人的反应要更自然：
   - 不要像NPC，加入闲聊、打量、低声议论
   - "这人怎么穿成这样？""是不是哪个剧组的？"

**保留的优点**：
- 装置内的主观视角
- "博物馆"这个词的冲击

## 第2章修改要点

### 致命伤：情绪转折太快，缺少挣扎过程

**具体修改**：
1. 压缩车厢对话段：
   - 三人坐着聊天的静态对话太长
   - 穿插：车外景色的变化、阿尔斯身体不适、内心挣扎
   - 可以让阿尔斯中途下车想自己走，被拦回来

2. 增强故居前的情绪爆发：
   - 看到479年（父亲死亡年份）要有更强烈反应
   - 不要被C.C.和安妮丝轻易劝回去
   - 可以尝试翻墙、和守卫冲突、被强行拦下
   - 挣扎：想进去又知道进不去，情绪在崩溃边缘

3. C.C.借钱的动机要更清晰：
   - 不要突然掏钱就走
   - 可以是：看到阿尔斯身上没钱，冷淡地说"欠着"
   - 或者：交换条件，"明天带我去档案院"

**保留的优点**：
- 安妮丝的碎碎念

## 第3章修改要点

### 致命伤：前半段日常拖节奏

**具体修改**：
1. 压缩开篇日常：
   - 醒来、穿衣、吃早餐压缩到2-3段
   - 快速切入"去档案院"

2. 莉迪亚的拒绝理由更人性化：
   - 不要只念"规定就是规定"
   - 加入："你知道多少人冒充格雷拉特吗？上个月就有..."
   - 或者："我理解你的心情，但我也要保住工作"

3. 删除或改写拉钩段落：
   - 太幼稚，换成握手或口头约定
   - 或者改成安妮丝自己拉钩发誓，阿尔斯只是看着

**保留的优点**：
- C.C.的"路过"梗
- 阿尔斯"我不能再等了"的决心
- 侦察地形的转变

## 修改原则

1. **情绪优先**：每个关键转折点都要有足够的情绪铺垫和释放
2. **冲突强化**：人物之间的对抗要更激烈
3. **节奏控制**：删减日常拖沓，保留核心冲突
4. **人物一致性**：阿尔斯要"行动快于思考"，不要太理性
