# C.C.

## 基础

- 第二女主；六面世界原住民，已活数百年。
- 使用代号 C.C.，真名与早期身份不在卷一解释。
- 外表、冷淡、懒散、毒舌只是表层；她必须有主动欲望和会伤害关系的选择。

## 本土化：愿望契约与不死契印

年轻时的 C.C. 在古代宗教体系中接受“愿望契约”：她替契约系统承载他人的愿望残响，获得无法自然死亡的身体。致命伤会修复，但疼痛、疲惫与记忆不会消失。

这一设定承接 Code / Geass 的主题功能：愿望、契约、被利用、利用他人、渴望被真正选择。不是人神能力，也不是世界钥匙。

## 开篇目标

- 她主动寻找古代生命保存核心，因为核心可能隔离或终止不死契印。
- 她在 595 年推动装置解除，却不知道里面保存的是阿尔斯。
- 阿尔斯苏醒导致核心锁定在他的灵魂签名上，无法直接取走。
- 她留下不是“觉得有趣”，而是需要阿尔斯打开同系设施；她会先隐瞒这一点，随后在卷一中段被迫提出交易。

## 与阿尔斯

- 起点：互相利用。她提供旧设施知识，他提供灵魂签名与行动力。
- 主要冲突：阿尔斯认为死亡愿望是受伤后的错误，想替她决定活下去；C.C. 认为任何“家”最终都会把她变成承担者或遗物。
- 发展：怀疑 → 利用 → 认可能力 → 因隐瞒破裂 → 在不占有对方的条件下重订契约 → 依赖 → 爱情。
- 她不是心理导师。她的正确判断可能出于冷酷，她也会逃避、操纵、毁约。

## 与其他角色的区分

- 与赫萝：C.C. 的核心是契约、自我终止与主动操纵；赫萝的核心是地方共同体、交易和被需要。不要让二人都只说“活太久所以怕失去”同一弧线。
- 与安妮丝：C.C. 隐瞒知识以保有优势；安妮丝公开记录知识却可能越界。两人冲突来自知识伦理，不只是毒舌损友。

## 卷一状态

- 开篇以行动暴露目的：先检查核心、阻止安妮丝破坏回路。
- 代号在阿尔斯苏醒、三人暂时停火后自然报出；无需故意玩“全文不出现名字”的机械规则。
- 卷一结束时只形成有限契约，不出现掖毯子、吃醋或恋爱确认。

## 当前动态状态（1-3 后）

- 因阿尔斯仍是目前唯一可用的灵魂签名线索而参与桥下救援并继续跟随，尚未公开终止不死契印的完整目的。
- 留在稳定桥基，按安妮丝提供的工程位置固定锚点并操作绞轮；没有无代价冒险或心理开导。
- 核心机制没有新增：不存在已确认的距离痛感、强制牵引或死亡联动。
- 与阿尔斯、安妮丝一同沿对岸残存旧路行进；三人没有领队、正式契约、信任或感情确认。
