# 1-3 正文提示词（重写版）

写第一卷第三章《谁替你收拾行李》，正文约 3000—5000 汉字，紧贴阿尔斯。

## 中心

写出阿尔斯小事依赖别人、大事抢决定权的矛盾。困难来自补给、等待、路线和羞耻，不来自大型灾难。

## 必写

- 伊沃允许三人等最后一辆工程货车。
- 阿尔斯出发时寻找不存在的行军包，意识到水、食物、外衣、药和路具过去总会出现。
- 关于爱夏的记忆必须表现她的工作判断、脾气和拒绝，不只表现照料。
- 安妮丝未经许可做身体检查，被制止后道歉却继续记录；她为追人推迟正式交接。
- C.C.只为自己谈到车位和食物，先行抵达白堤。
- 阿尔斯因羞耻独走旧路，旧路被私人地界和新桥引道截断；几百字内完成，不安排坍塌。
- 安妮丝因责任追来，也因追人中断正式交接；两人互相迁怒。
- 深夜三人在白堤收费所重新会合，不建立规则、信任或温情。

## 禁止

不写铁撑、锚点、绞轮、大坍塌、连续重伤或成熟总结。
