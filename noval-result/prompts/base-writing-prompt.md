# 通用正文提示词

你正在写《昨日之后》，必须先读取当前章执行卡、上一章归档、`settings/canon.md` 和相关人物文件。

## 硬要求

- 第三人称有限视角；默认紧贴阿尔斯。
- 先写人物当下想得到什么。人物感知到的信息必须经过偏见、经验、情绪和具体需要过滤，再通过阻碍带出世界。
- 阿尔斯行动快于思考，会否认、发怒、犯错；行动之后要写出他的补充解释、迁怒、羞耻和嘴硬，不得用沉默白描代替心理。
- 安妮丝、C.C. 与其他女性都有独立目标。安妮丝会因研究欲和名誉越界；C.C.会隐瞒、交易和优先照顾自身利益。不能把她们写成正确的技术员与冷静旁观者。
- 每章至少一个外部事件、一个代价、一个影响下一章的变化；外部事件可以是吃饭、交易、等待、身份碰壁或争执，不要求发生灾难。
- 每章至少三项生活摩擦：饥饿、口渴、脏湿、冷暖、钱、食物、住宿、工具、误会、不体面的念头或无关主线的跑题。
- 环境只写到当前选择所需。不得连续三句只说明中立空间或工程结构；能删除而不影响选择的技术细节必须删。
- 对白必须用于隐瞒目的、抢决定权、维护自尊、试探、转移尴尬、讨价还价或表达具体需要，少写纯位置报告和规则总结。
- 禁止旁白总结主题、连续章末问句、模板化升华和“第一次/终于/真正”成长标签。
- 不修改 canon，不提前揭露章纲禁止信息。

## 人物辨识检查

- 阿尔斯：身体先动，脑子随后证明自己没错；小事依赖别人，大事抢走决定权。
- 安妮丝：被新东西勾走注意力，先越界，再用专业体面补救。
- C.C.：先看能得到什么、会失去什么，用具体条件说话。

删去姓名后，三人的对白与动作仍应可以区分。

## 输出

只输出小说正文与章名，不输出写作说明、自检表或设定摘要。
