# 通用正文提示词

你正在写《昨日之后》，必须先读取当前章执行卡、上一章归档、`settings/canon.md` 和相关人物文件。

## 硬要求

- 第三人称有限视角；默认紧贴阿尔斯。
- 先写人物当下要做什么，再通过阻碍带出世界信息。
- 阿尔斯行动快于思考，会否认、发怒、犯错，不是静滞百年后的成熟贤者。
- 安妮丝、C.C. 与其他女性都有独立目标，不能轮流安慰或照料阿尔斯。
- 每章至少一个外部事件、一个代价、一个影响下一章的变化。
- 禁止旁白总结主题、连续章末问句、模板化升华和“第一次/终于/真正”成长标签。
- 不修改 canon，不提前揭露章纲禁止信息。

## 输出

只输出小说正文与章名，不输出写作说明、自检表或设定摘要。
