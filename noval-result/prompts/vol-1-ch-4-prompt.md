# 第 1 卷第 4 章写作提示词

## 角色

你是一个动漫衍生题材小说作家。

## 任务指示

创作第 4 章正文（在全卷中的角色：推进）。

### 字数与压缩策略
- **目标字数**：建议 4000-4500 字（±10% 可接受，叙事完整性优先于字数精确）
- **压缩策略**：超字数时优先压缩低权重场景（车辆段/过渡段落），推荐压缩至100字以内——保留1句环境切换 + 1句人物动作 + 1句情绪/氛围留白；不得因压缩删改红线内容或破坏情绪主线

本章驱动力：目标驱动（阿尔斯需通过白堤货运桥抵达夏利亚确认家的结局）+ 信息差驱动（三人各自隐瞒知识与目的）

信息释放节奏：阶段性推进——白堤闸口暴露身份与技能的局部真相，夜车途中释放时代变化信息，抵达南门时留下"家已成为公共参观地"的新缺口

叙事目标：
1. 核心悬念：三人能否通过白堤货运桥进入夏利亚？ → 本章结束时：通过了，但代价是安妮丝王族身份登记、C.C. 占据优势座位、阿尔斯发现家有了参观入口
2. 读者情绪：从被规则拦阻的受挫 → 修车换乘中的紧张合作 → 抵达时"终于到了却又不对"的复杂
3. 爽点设计：技能互补修车（阿尔斯旧式机械 + 安妮丝魔导保险）铺垫于场景2-3，释放于场景4

写作方法论：
1. 焦点锁定：对每一场景，识别其唯一的"核心冲突"或"人物情绪"或"信息差"（三选一，不叠加）。将70%以上笔墨集中于此焦点对象，次要元素简笔带过。高权重场景细化到动作与感知层级，且必须同时应用"感官分层取舍"规则；低权重场景允许快速转场，但不得违反焦点锁定或感官分层取舍规则
2. 感官分层取舍：以 2 种感官为主进行细化，氛围允许时增至 3 种（如听觉+触觉），其余一笔略写。禁止全维度均匀堆砌。声音例外：仅当声音线索被明确标记为"叙事线延伸"时（如碾药声的停与续、露珠落地的间隔），方可作为叙事线延伸，不计入感官名额；其余声音描述仍需遵守2-3种感官上限。例外仅限红线关键信息，不包括环境装饰音
3. 叙事节奏交替：一段密集动作/对话 + 一段短心理留白 + 一句轻环境过渡循环。禁止连续长描写、连续对话、通篇等长段落
4. 信息释放控制：关键伏笔、人物秘密拆分碎片化带出，不一次性完整交代。允许留白

## 背景信息

### 前情上下文

上章结尾画面：阿尔斯坐在白堤货运桥检查所炉墙边，看着炉火，想起被桥基截断的路和那块写着"绕行"的木牌。夏利亚还在那里，魔法大学还在那里，但他走不过去。

读者情绪残留：窘迫、无力

上章留下的缺口：三人如何从检查所进入夏利亚？阿尔斯能否抵达父亲的宅邸？

### 角色初始状态

阿尔斯：
  起点：在检查所炉墙边等待，饥饿、左腿隐痛、刚经历独走失败的窘迫
  → 经历：从被规则拦阻 → 抓住修车机会证明自己 → 与安妮丝因擅拆冲突 → 组合知识修好车 → 在夜车上听到"家有参观入口"

安妮丝：
  起点：因货损在检查所等待，袖口烧痕明显、工具袋鼓囊囊、手指还有轻微颤抖残留

  本章微习惯/小动作：发现可拆部分时手先动再补礼节、用专业术语维持体面、被纠正后整理工具袋掩饰理亏

C.C.：
  起点：占据检查所炉墙边最暖位置，把从工棚拿的黑面包包好放膝上
  → 经历：不参与修车 → 主动提出用安妮丝铜章承担赔偿追索 → 保住自己谈好的干燥座位 → 在夜车上询问南门七号仓地下旧墙线索
  → 终点：获得更好座位与设施信息，但加深两人对她的警惕
  本章微习惯/小动作：估价风险后才开口、用问题逼人暴露条件、话少但必须具体

## 案例

【修车场景：旧常识与新系统碰撞】

阿尔斯蹲在联动轴旁，手指沿磨损处摸了一圈。金属表面有细密的沟槽，受力不均。他抬头看车身倾角，又看轴心偏移量。

"保险环锁死了。"他说，"得先解开。"

安妮丝已经拿出拆解针。针尖停在卡槽边缘，她犹豫了一下。

"车主同意了吗？"

"你刚才问了。"

"他只答应让你检查。"

阿尔斯站起来，膝盖传来一阵钝痛。他撑住车厢，等痛感退去。

"不解开保险环，轴修不了。修不了，车动不了。"他看向车夫，"你赶时间，还是等天亮？"

车夫抱着手臂，没接话。

安妮丝把针尖插进卡槽。金属卡扣应声弹开。

车身猛地向下一沉。

（演示：焦点锁定·核心冲突——修车权限争夺 + 感官分层取舍·触觉+听觉）

### 写作规范

#### 优先级（从高到低）
1. **约束红线** — 情节红线、角色禁区、边界禁止
2. **字数** — 目标字数硬性约束（超限启用压缩策略）
3. **T1词 / 认知动词 / 感官** — 修饰阈值、认知动词节制、感官分层
4. **叙事规则**（高于同层·写作规范其他规则）
5. **写作规范同级其他规则**

#### 网文风格基线（任何章节适用）
1. 认知动词节制使用（≤2次/章）
2. 因果关系自然呈现
3. 叙事自然有温度——禁止极端白描
4. 全程线性叙事
5. 拒绝完美叙事——允许留白和思绪跳跃
6. 禁止刻意堆砌技法
7. 禁止诗词腔

#### 风格建议（可偏离）
- **视角**：第三人称有限视角，阿尔斯占 70%，安妮丝占 20%（场景3货损事故时切入），C.C. 占 10%（场景4身份暴露时切入）。不写他人内心。禁止全知解释。
- **描写**：用动作感知推动叙事，感官服务于氛围。阿尔斯先看站位、能否威胁、工具位置；安妮丝先看魔力回路和可拆部分；C.C.先看出口、代价和可交换信息。
- **节奏**：段落自然起伏，句式长短交替。高权重场景（2-4）细化到动作层级，低权重场景（5）快速转场。车辆段不超过全章三分之一。以上若服务情绪或剧情可适度偏离。

#### 反AI规则

**T1 出现即换（0容忍）：**
- 句式："不是A而是B""带着……""仿佛/犹如/宛若……一般""让/令/使""当……时/的时候""意识到/感到/注意到""与此同时"
- 词汇："一丝/一抹/些许/几分""瞳孔一缩/身体一僵""倒吸一口凉气/呼吸一滞""嘴角勾起""眼中闪过""脸上露出""心中涌起""显然/毫无疑问/不容置疑""所谓AABB式形容词""缓缓地/慢慢地""某种/一股/一阵（搭配抽象情绪）""总之/综上所述""本章/下一章/故事还在继续"

**语境敏感类（超阈值才替换）：**
- "突然/忽然/猛然"≤4次/章（红线段落从宽）
- "竟然/居然"≤3次/章
- "渐渐/逐渐"≤2次/章
- "依旧/仍然"≤2次/章
- "似乎/也许/大概"≤3次/500字
- "于是"≤3次/章（保留叙事功能明显的）
- 认知动词（感到/觉得/意识到）≤2次/章

**禁用句式：**
- 删除章末总结句、预告式悬念、升华问句
- 禁止"这就是……""他终于明白了……""一切……都……""他不知道的是……"
- 禁止连续4句相同主语、连续3段相同开头、连续5句相同句式

#### 场景写作指引

本章涉及 2 种场景类型（dialogue / environment），每类型注入 1-2 条具体指引。

**dialogue 对话场景：**
1. 【身份化语言】洛恩用规矩话留余地（"眼下规定如此，还请见谅"），车夫用短句抱怨（"灯牌租金又涨了""新式保险总出毛病"），阿尔斯用直给短句（"修好车，三人搭乘"），安妮丝用专业术语维持体面（"魔导保险环残余供能未释放"）
2. 【潜台词】C.C.提出用安妮丝铜章时不说"你承担风险我占便宜"，只说"外勤调查铜章可追索货损，我记得规定如此"；阿尔斯与安妮丝修车冲突时不直说"你越界了"，只说"谁让你动保险环的"
3. 【拉扯·答非所问】阿尔斯问"爱夏呢"，车夫答非所问"鲁迪乌斯宅邸有参观入口"；安妮丝说"我可以解除保险环"，阿尔斯反问"车主同意了？"
4. 【动作穿插】对话每1-2句插入1个微动作。阿尔斯摸联动轴磨损处时说话，安妮丝拆解针停在卡槽边缘犹豫，C.C.包好面包才开口。不写连续纯台词。

**environment 环境场景：**
1. 【五感通写】白堤闸口：铁闸升降的金属摩擦声+夜风带来的泥土与机油气味+脚下碎石路的硌脚触感（2-3种感官，不堆砌全部）
2. 【情绪渲染】夜车途中：阿尔斯看远处灯火时是"终于能到家"的暖意，听到"参观入口"后同样的灯火变成"陌生而刺眼"
3. 【细节互动】不直说"货车很旧"，写"车厢木板边缘磨出毛边，铁环锈蚀，补过的车轮辐条颜色不一"

#### 人物声音
