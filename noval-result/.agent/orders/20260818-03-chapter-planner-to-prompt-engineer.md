# 交接：章节规划 → 提示工程

- 每章至少用三项生活摩擦承载人物，不让环境成为独立展示。
- 阿尔斯：先自我辩护再被物证逼退；嘴硬，不能迅速领悟主题。
- 安妮丝：研究兴奋、越界、会认小错但不会自动正确。
- C.C.：少说、先谈自己的利益、主动试探核心线索。
- 爱夏回忆必须包含独立判断与脾气，不能只剩照料功能。
- 对话每场只设一个主要目标，三人以上每两三轮重新锚定说话者；同场最多一次完整机锋。
- 外貌必须绑定动作与视角：安妮丝的金发绿眼、灰污外勤装和向前扑的体态；C.C.的腰下绿发、金眼、苍白静止感与古式黑衣。
- 新增地方设施必须挂在夏利亚东南郊交通体系下，并区分 465 年称呼与 595 年称呼。
