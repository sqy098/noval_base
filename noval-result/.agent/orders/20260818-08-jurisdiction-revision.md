# 管辖与安妮丝身份修订交接

- 作者决定：白堤第七开掘区继续位于拉诺亚王国魔法都市夏利亚东南郊，不迁往阿斯拉王国。
- “帕雷蒂亚王国”设定作废。“帕雷蒂亚”改为阿斯拉王族近百年间形成的旁支家名；安妮丝正式宫廷姓名为“安妮丝菲亚·温·帕雷蒂亚·阿斯拉”，日常省略末尾国姓。
- 安妮丝保留旁支王女称号与遥远继承顺位，但在拉诺亚没有行政权。她进入遗迹与提交报告的资格来自拉诺亚魔法大学古代术式研究室及魔术公会的外聘研究职务。
- 白堤第七开掘区：夏利亚地方工程会管理土地、施工、现场封锁与赔偿；夏利亚守卫负责治安；拉诺亚王家档案院夏利亚分室负责身份与历史档案。
- 后续禁止回流：帕雷蒂亚王国、帕雷蒂亚王立魔导院、帕雷蒂亚—拉诺亚联合开掘、王女凭头衔在拉诺亚直接放行或调档。
