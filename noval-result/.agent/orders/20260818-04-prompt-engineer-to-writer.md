# 交接：提示工程 → 正文写作

- 视角：紧贴当章人物感知与自我辩护，避免连续中性空间说明。
- 技术：只保留能制造争执、选择或损失的细节。
- 对话：每场先确定一个目标，不让所有人轮流说漂亮反击句；工人与车夫先关心饭、班次、货损和赔偿。
- 情绪：阿尔斯听见 595 年后立即完成算术，身体已明白而嘴拒绝承认；通过抢地图、失手、呼喊爱夏与立刻回家呈现。
- 地理：使用夏利亚、拉诺亚魔法大学、学生区、鲁迪乌斯宅邸等原作锚点；“灰榆运材道/东林场作业道”只作双时代地方名。
- 外貌：首次同场给出发、眼、脸、体态、衣装或手部细节，后续通过脏污、姿势和衣物变化维持，不做人物图鉴。
- 禁止：复刻任何在世作者的具体句法或现成句子；只吸收主观视角、生活摩擦、严肃与尴尬并存等高层特征。
