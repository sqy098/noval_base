## 二、蛇足编3卷（阿尔斯-爱夏篇）使用规范

### 背景事实（必须遵守）
1. **关系性质：** 阿尔斯（侄子）与爱夏（姑姑）发展出超越正常姑侄的关系
2. **家族危机：** 关系曝光后引发格雷拉特家族"最大危机"
3. **人物年龄：** 关系发展在两人均成年后
4. **爱夏人设：** 天生天才、全能型、强势、占有欲强、能力超群

### 《昨日之后》的分歧点
**本作与原作蛇足编的关键差异：**

| 要素 | 原作蛇足编 | 《昨日之后》设定 |
|---|---|---|
| 关系结局 | 最终结合（书籍版后日谈） | 关系曝光后数日/数周，阿尔斯即遭遇静滞事故 |
| 家族反应 | （待确认，可能包含接受过程） | 冲突未解决即被静滞打断 |
| 阿尔斯发展 | 成长后正式向爱夏告白 | 情感与责任认知冻结在事故时 |
| 爱夏后续 | （待确认） | 130年人生：搜索→工作→建立援助网络→自然离世 |

**分歧原因：** 静滞事故提前终止了原作中的关系发展，将"未解决的家族危机"冻结为阿尔斯的永久背景。

### 使用边界（不过度展开原则）

#### ✅ 可以使用的部分
1. **人物底色：**
   - 爱夏的能力、性格、行为方式（天才全能型、强势、管理倾向）
   - 阿尔斯对爱夏的依赖模式（习惯她替自己做决定、矛盾心理）
   - 关系的复杂性（超出正常姑侄，但不明写具体细节）

2. **背景事实：**
   - 关系在成年后曝光
   - 引发家族冲突（"家庭风暴"）
   - 冲突未解决即发生静滞事故

3. **记忆片段：**
   - 爱夏如何管理阿尔斯的任务、装备、行动
   - 两人的争执、她的强势、他的服从/反抗
   - 暗示关系的特殊性（但不详细描写）

#### ❌ 禁止展开的部分
1. **关系细节：**
   - 不详细描写关系如何发展（何时开始、如何表白、具体互动）
   - 不描写亲密场景或情感细节
   - 不让阿尔斯在前期频繁回忆"我们当时..."

2. **家族冲突细节：**
   - 前5章不展开鲁迪乌斯、艾莉丝、希露菲等人的具体反应
   - 不描写家族会议、争吵场景、谁说了什么
   - 保留到第5卷通过档案、他人视角逐步揭示

3. **伦理讨论：**
   - 不让角色（包括阿尔斯）进行道德判断或自我辩护
   - 不写"这段感情是对是错"的内心独白
   - 通过行为和后果展现，不通过议论展现

#### 📏 使用尺度示例

**❌ 过度展开（禁止）：**
> "阿尔斯想起那天爱夏终于对他说出那句话的场景。她的手很凉，握住他的手腕时他感觉到她在颤抖。她说'我知道这不对，但我...' 他打断了她，说'我也一样。'从那天起，他们再也回不去普通的姑侄关系了。"

**✅ 合理暗示（允许）：**
> "他伸手向右肩后摸，那里应该有行军包的背带。手落空。他顿了一下，才想起包不在。爱夏会在出发前检查清单，把缺的补上，多的拿走。她每次都说'你带这些是想干什么'，语气里有责备，也有她从不解释的别的东西。最后还是她赢。"

**区别：** 前者明写关系发展，后者只通过行为暗示"关系不简单"。

## 三、格雷拉特家族设定约束

### 家族结构（原作事实）
- **鲁迪乌斯·格雷拉特：** 七大列强之一、魔法教育改革者、三妻（希露菲、洛琪希、艾莉丝）
- **子女：** 露西（希露菲之女）、拉拉（洛琪希之女）、阿尔斯（艾莉丝之子）、克丽斯蒂娜（艾莉丝之女）等
- **爱夏·格雷拉特：** 鲁迪乌斯同父异母妹妹、格雷拉特家核心成员、天生天才

### 家族地位（本作必须体现）
1. **历史影响力：** 鲁迪乌斯去世114年后（595年），格雷拉特家仍是历史名词
2. **宅邸历史化：** "鲁迪乌斯宅邸"有管理处、参观入口，成为历史遗产
3. **社会认知：** "阿尔斯·格雷拉特"的姓氏会被立刻认出并产生反应

### 家族冲突（保留到后期展开）
**已知事实：**
- 阿尔斯与爱夏关系曝光引发"家庭风暴"
- 冲突未解决即发生静滞事故
- 爱夏长期寻找阿尔斯（初期与家人争执、中期转为档案工作）

**卷一处理方式：**
- 只通过暗示让读者知道"阿尔斯家庭背景复杂"
- 不展开具体冲突内容
- 不让阿尔斯主动回忆或讨论

**第五卷展开方式：**
- 通过爱夏的档案、他人记忆、机构记录拼接
- 多视角呈现（不只阿尔斯视角）
- 展现家人的痛苦、分歧、寻找过程、接受/不接受的复杂性

## 四、世界观约束（六面世界设定）

### 必须遵守的原作设定
1. **魔法体系：** 无咏唱魔法、治愈魔法、召唤魔法、结界魔法、魔眼
2. **剑术流派：** 剑神流、水神流、北神流
3. **种族寿命：** 人族约80年、魔族数百年、龙族千年+
4. **地理结构：** 中央大陆、魔大陆、天大陆、南方大陆、东南大陆
5. **势力格局：** 阿斯拉王国、拉诺亚王国、米里斯神圣国、大森林等
6. **历史人物：** 七大列强、龙神奥尔斯帝德、人神（已失去干涉能力）

### 130年后的合理演进
**允许的变化：**
- 魔导工业化（基于鲁迪乌斯的魔法教育改革）
- 城市扩张、交通改善、行政规范化
- 术式标准化、魔导器械普及
- 社会结构变化（土地金融化、新资本家崛起）

**禁止的变化：**
- 跳跃到现代科技（电子设备、互联网、现代都市）
- 改变魔法基础规则（如突然可以咏唱加强、创造新魔法系统）
- 让短寿种族无故延寿
- 创造原作中不存在的大陆或主要国家

## 五、综漫角色约束

### 本土化强制要求
**所有非原作角色必须：**
1. **完全用六面世界体系解释能力来源**
2. **从六面世界社会制度中生长身份**
3. **不保留原作品的世界观元素**

### 具体禁止事项
| 角色 | 原作品 | 禁止引入的元素 |
|---|---|---|
| C.C. | Code Geass | Geass能力、Code不死诅咒、皇帝契约 |
| 安妮丝 | 转生恶役千金 | 魔法工学机甲、现代工学知识、游戏世界设定 |
| 赫萝 | 狼与香辛料 | 神明身份、麦穗契约、收获女神体系 |

### 允许保留的部分
- **外貌特征**（如C.C.的绿发金眼）
- **核心性格**（如安妮丝的研究欲、C.C.的冷漠自利）
- **人际模式**（如赫萝的商业头脑、语言风格）

## 六、代理使用指引

### 写作代理（writer、anti-ai）
- 写爱夏时参考蛇足编人设，但只写行为方式，不展开关系细节
- 阿尔斯回忆爱夏时，只写她如何管理他、如何争执，不写情感发展
- 暗示关系特殊性用"她从不解释的别的东西"等模糊描写

### 评审代理（reader）
- 检查爱夏是否扁平化（对比蛇足编中的天才全能型人设）
- 检查是否过度展开关系细节（超过"暗示"程度即为过度）
- 检查家族冲突是否过早透露

### 设定维护代理（updater）
- 新增原作相关内容时，必须在本文件登记边界
- 发现与原作冲突时，优先保护原作设定，修改二创内容
- 蛇足编相关内容分"可用底色"和"不展开细节"两类管理

## 七、评审检查清单

每章完成后必须检查：

### 原作一致性
- [ ] 魔法使用是否符合六面世界体系？
- [ ] 人物行为是否符合原作人设？
- [ ] 是否尊重格雷拉特家族的历史地位？
- [ ] 是否违反原作已确定的世界观规则？

### 蛇足编边界
- [ ] 爱夏的能力、性格是否符合"天生天才"设定？
- [ ] 是否过度展开了阿尔斯-爱夏关系细节？
- [ ] 是否过早透露了家族冲突内容？
- [ ] 暗示程度是否控制在"读者知道关系不简单"的范围内？

### 综漫本土化
- [ ] 综漫角色是否完全用六面世界体系解释？
- [ ] 是否引入了原作品的世界观元素？
- [ ] 是否破坏了《无职转生》世界的完整性？
