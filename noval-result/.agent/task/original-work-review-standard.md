# 原作背景评审标准

**适用范围：** 所有章节评审必须加入此项审视

## 核心原则

《昨日之后》是《无职转生》后日谈 × 六面世界本土化综漫。评审时必须确保：

1. **不偏离六面世界基础设定**
2. **尊重原作已建立的世界规则**
3. **保持与原作人物/家族的合理连续性**
4. **避免为综漫便利性破坏原作逻辑**

## 必查项目

### 1. 世界观一致性

**原作基础：**
- 六面世界魔法体系（无咏唱、剑术流派、魔眼、龙族、魔族等）
- 种族寿命差异（人族约80年、魔族数百年、龙族千年以上）
- 地理结构（中央大陆、魔大陆、天大陆等）
- 甲龙历纪年体系
- 格雷拉特家族的历史地位与声望

**评审要点：**
- ✓ 魔法使用是否符合六面世界体系（不要凭空创造新魔法系统）
- ✓ 种族特征是否与原作一致（精灵、魔族、龙族的特性）
- ✓ 地名、机构名是否与原作地理相容
- ✓ 130年时间跨度的合理性（对不同种族的意义）

**禁止：**
- ❌ 引入原作中不存在的魔法类型或能量体系
- ❌ 让短寿种族（人族）在没有特殊原因下活过百年
- ❌ 创造原作中明确不存在的国家或大陆
- ❌ 无视原作中已确立的魔法限制

### 2. 格雷拉特家族设定

**原作基础：**
- 鲁迪乌斯·格雷拉特的传奇地位（七大列强、魔法创新、教育改革）
- 家族成员：希露菲、洛琪希、艾莉丝三位妻子，多名子女
- 阿尔斯在原作中：鲁迪乌斯与爱夏的儿子，与爱夏的关系在原作中有暧昧暗示
- 爱夏的能力：管家型万能人才，实务能力极强

**评审要点：**
- ✓ 鲁迪乌斯的影响力是否符合原作设定（他应该是历史级人物）
- ✓ 格雷拉特家宅的规模与地位是否匹配（不应该是普通民宅）
- ✓ 阿尔斯的能力来源是否合理（父亲的教导、家族资源）
- ✓ 爱夏的人物特质是否保留（能干、强势、照料但非保姆）

**禁止：**
- ❌ 把鲁迪乌斯矮化为普通魔法师
- ❌ 把格雷拉特家写成没落小贵族
- ❌ 无视阿尔斯作为"那个格雷拉特的儿子"应有的社会认知度
- ❌ 把爱夏扁平化为"收拾行李的人"（原作中她是极强能力者）

### 3. 时代演进合理性

**原作基础：**
- 鲁迪乌斯生前推动了魔法教育改革、术式标准化
- 六面世界原本处于中世纪早期水平
- 130年足够让技术和社会发生显著变化

**评审要点：**
- ✓ 魔导工业化是否建立在鲁迪乌斯的遗产基础上
- ✓ 变化速度是否合理（不要一夜现代化）
- ✓ 旧时代痕迹是否保留（不是全面替换）
- ✓ 阿尔斯的知识是否在某些方面仍有价值

**禁止：**
- ❌ 让世界变化与鲁迪乌斯的影响完全脱钩
- ❌ 130年内跳跃到现代科技水平
- ❌ 让所有旧知识都变成无用垃圾
- ❌ 无视原作中已存在的魔法学院、公会等机构

### 4. 人物关系的原作底色

**原作敏感点：**
- 阿尔斯与爱夏的关系在原作中有伦理争议
- 格雷拉特家族内部关系复杂（多妻、多子女）
- 奥尔斯帝德、人神等关键角色的立场

**评审要点：**
- ✓ 阿尔斯与爱夏关系的处理是否尊重原作暗示但不回避复杂性
- ✓ 家族冲突是否符合原作人物性格（希露菲温和、艾莉丝激烈等）
- ✓ 奥尔斯帝德等原作角色出场时是否符合其人设

**禁止：**
- ❌ 把阿尔斯与爱夏的关系简化为"兄妹温情"或"纯粹禁忌"
- ❌ 让格雷拉特家族成员对关系曝光的反应过于现代化或过于温和
- ❌ 让奥尔斯帝德变成万能答案机或消失不管

### 5. 综漫角色的六面世界化

**本作特殊性：**
- C.C.、安妮丝、赫萝等角色来自其他作品
- 必须完全本土化为六面世界原住民

**评审要点：**
- ✓ 综漫角色的能力是否用六面世界体系重新解释
- ✓ 综漫角色的存在是否与原作世界观冲突
- ✓ 综漫角色是否抢夺了原作设定的核心位置

**禁止：**
- ❌ 让综漫角色保留原作品的世界观（如C.C.的Geass、安妮丝的机甲）
- ❌ 让综漫角色的存在需要"跨界"解释
- ❌ 为综漫角色便利而修改《无职转生》世界规则

## 评审流程

每章评审必须增加以下环节：

1. **世界观检查：** 本章出现的魔法、种族、地理是否与原作兼容？
2. **格雷拉特家检查：** 涉及家族历史、成员、影响力的描写是否合理？
3. **时代感检查：** 130年变化是否建立在原作基础上？
4. **人物底色检查：** 阿尔斯、爱夏等原作角色是否保持原作特质？
5. **综漫融合检查：** 外来角色是否成功本土化，未破坏原作逻辑？

## 判定标准

**致命伤（必须修改）：**
- 直接违反《无职转生》世界观基础设定
- 矮化或扭曲原作核心角色（鲁迪乌斯、爱夏等）
- 让综漫角色的存在需要跨界解释
- 无视格雷拉特家族应有的历史地位

**主要问题（建议修改）：**
- 魔法使用细节与原作体系有出入
- 时代变化缺乏与鲁迪乌斯遗产的连接
- 人物关系处理过于简化原作复杂性

**可优化点：**
- 可以增加更多原作元素的呼应
- 可以强化六面世界特有的细节
- 可以更好地展现130年的时代感

## 使用说明

- 此标准从第3章重新评审开始启用
- 后续所有章节评审必须包含"原作背景审视"部分
- 评审报告格式：在常规评审后增加"## 原作背景审视"章节
