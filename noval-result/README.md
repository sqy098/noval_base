# 《昨日之后》Novel Agent 工程

这是从 `noval/` 重构出的独立版本。旧工程仅作为素材来源，不是本目录的设定依据。

## 当前定位

- 工作标题：《昨日之后》
- 原作基底：《无职转生》后日谈
- 核心主角：阿尔斯·格雷拉特
- 核心事件：甲龙历 465 年，阿尔斯在一次遗迹事故中被**非自愿静滞**；甲龙历 595 年苏醒
- 核心主题：一个失去整个旧家的人，重新学习“家是什么、怎样与别人共同建立家”
- 长篇规模：9 卷，预计 380—430 章；以有效事件为准，不以章数配额填充

## 开始工作

1. 先读 `AGENTS.md`。
2. 任何代理先读 `.agent/task/setting-brief.md`、`settings/canon.md` 与 `.agent/project-state.md`。
3. 总纲以 `story.md` 为准，分卷以 `volumes/` 为准，当前章以 `chapters/` 为准。
4. 正文写入 `archives/`；归档后由 continuity/updater 同步人物、时间线、伏笔和项目状态。

## 与旧版的关键差异

- 静滞是事故，不是阿尔斯的主动选择，也不存在“自愿静滞但失忆”。
- 安妮丝不是默认第一女主；第一女主仍是作者决策项。
- 白堤第七开掘区位于拉诺亚王国夏利亚东南郊；安妮丝是阿斯拉王族旁支，但在拉诺亚的调查权来自魔法大学与魔术公会，不来自王族头衔。
- C.C. 保留契约、愿望与终结不死的主动欲望，不再只是神秘旁观者。
- 赫萝卷一不入队，卷二作为地方盟友登场。
- 旧版卷一 36 章与全书 316 章配额全部作废。
- 不使用人神复活、跨世界裂隙或幕后大阴谋推动主线。
